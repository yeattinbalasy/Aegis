# AEGIS AI SIEM — интерактивный прототип СРО 2

Прототип демонстрирует пять экранов: обзор, события, инциденты, AI-модуль и архитектуру. Фильтры событий, поиск, открытие карточки инцидента и изменение демонстрационного статуса интерактивны.

Все события и метрики синтетические. Они не являются результатами обучения или испытаний модели.

## Локальный запуск

Откройте `dist/index.html` в браузере. Если браузер ограничивает локальные сценарии, запустите любой статический веб-сервер из каталога проекта и откройте папку `dist`.

Файл `.openai/hosting.json` содержит конфигурацию публикации в Sites.
